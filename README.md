# Gacha-game

## Memory Shards system

Major battles now leave behind **Memory Shards**. Each shard captures a pivotal moment—triumphs, betrayals, fears—and can be slotted onto units from the Team page.

- Earn shards by completing or failing stages.
- Equip up to three shards per unit to modify stats and unlock narrative flavor.
- Fuse two shards to form hybrids (e.g., "Fear of Fire" + "Pyromancer Training" → "Unstable Flame Channeler").
- Shard conflicts can penalize teams that carry incompatible memories, making party composition more strategic.
